# Implementation Plan: renderer-export

**Branch**: `feat/renderer-export` | **Date**: 2026-09-29 | **Spec**: `specs/007-renderer-export/spec.md`

**Input**: Feature specification from `specs/007-renderer-export/spec.md`

## Summary

Bring the poster renderer into the browser and add PNG/SVG/PDF export, with
`render-spec.json` as its normative contract (ADR-0003; the Python renderer
was removed by BCR-0005). Delivered in two refactor slices: the flagged poster
renderer (slice 3) then the exports (slice 4).

## Technical Context

**Language/Version**: TypeScript 7 (native `tsgo`), React (latest), Bun (runtime, package manager, `bun:test`); Vite build.

**Primary Dependencies**: React, Vite, `pako` (share codec), `svg2pdf.js` + `jsPDF` (vector PDF); no server-side dependency.

**Storage**: none — `catalog.json` and `constellations.json` fetched from the same origin (ADR-0002); font bundled.

**Testing**: `bun:test` for units and conformance; a browser reference-image suite for visual regression; Playwright journeys come from `qa:e2e`.

**Target Platform**: evergreen browsers, desktop and mobile; offline after first load.

**Project Type**: web application (single static client) + a Python CLI tool.

**Performance Goals**: poster render + export within budget on a mid-range phone; no full-page re-render on option change beyond the canvas.

**Constraints**: no network at render time; deterministic; bundle budget 500 KB brotli (excluding font); WCAG 2.2 AA.

**Scale/Scope**: up to a modelled viral spike (~8 req/s edge) handled by the CDN; browser work is per-visitor.

`lib/render/` module behind a `Renderer` interface (branch-by-abstraction,
`refactor.md` §5), so the existing preview remains the fallback until the
flagged poster renderer is proven.
